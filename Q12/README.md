# Q12 — E-commerce storefront demo

Open `index.html` in a browser. The demo supports product listings, a quantity-aware cart, local demo orders, and seller add/edit/delete controls. Products, cart, and orders are saved in that browser's local storage.

**Payments are intentionally simulated.** No card data is requested or stored and no payment provider is connected. This is a front-end lab, not a production storefront.
