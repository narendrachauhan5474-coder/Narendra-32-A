# Web Development Lab: Q1–Q13

Each `Q<number>` folder contains a standalone project for the corresponding lab experiment. Follow the README in each folder to run it. Static projects can be opened directly in a browser; Node.js projects require `npm install` followed by `npm start`.

The MongoDB and e-commerce payment examples are configured for local development. They do not include database credentials or process real payments.

## Experiments

1. Concentric circles
2. Ten horizontally aligned cards
3. Interactive to-do list
4. JavaScript-generated chessboard
5. Snakes and ladders
6. Random jokes API
7. Country university lookup API
8. Express routes with EJS
9. RESTful in-memory product CRUD
10. Product API with client-side rendering
11. MongoDB-backed product CRUD
12. E-commerce demo with cart, orders, seller panel, and mock checkout
13. React portfolio
